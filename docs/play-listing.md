# Тихо — описание для Google Play

**Название:** Тихо — приватный браузер

**Краткое описание (до 80 символов):**
Приватный браузер на движке Firefox: без трекеров, рекламы и телеметрии.

**Полное описание:**
Тихо — браузер для Android на движке GeckoView (Firefox), который бережёт вашу приватность.

• Строгая защита от отслеживания: блокировка трекеров, криптомайнеров и сторонних cookie.
• Защита от фингерпринтинга в духе Tor Browser: сайты видят вас как одного из многих.
• Встроенный блокировщик рекламы uBlock Origin.
• Только HTTPS, удаление трекинг-параметров из ссылок, Global Privacy Control.
• Безопасный режим для банков и оплаты: отдельное хранилище и предупреждения о фишинге.
• Приватные вкладки и очистка данных при выходе.
• Никакой телеметрии и сбора данных.

**Категория:** Связь / Браузеры
**Сбор данных (Data safety):** приложение не собирает и не передаёт данные пользователей.
