# Тихо для ПК

Настольная сборка Тихо для **Windows x64** и **Linux x86_64**.

## Что это

Первая настольная версия использует официальный Firefox ESR (движок Gecko), а не Chromium/Electron. Это позволяет сохранить совместимость с Firefox WebExtensions и использовать тот же uBlock Origin, что и Android-версия. Сборка не изменяет бинарники Mozilla: она добавляет конфигурацию приватности и политики браузера.

## Защита по умолчанию

- uBlock Origin устанавливается принудительно из официального каталога Mozilla Add-ons.
- Enhanced Tracking Protection — Strict.
- HTTPS-Only включён.
- Global Privacy Control включён.
- Resist Fingerprinting включён (может ухудшать совместимость отдельных сайтов).
- WebRTC остаётся доступен, но ограничивается для снижения утечек IP.
- Убраны телеметрия Firefox, исследования, Normandy и спекулятивные сетевые запросы.
- Кросс-сайтовый Referer обрезается до origin.
- Cookies, история, кэш, активные сессии и данные форм очищаются при закрытии браузера; пароли и закладки не входят в этот список.

## Скачать

GitHub Actions собирает два архива:
- `Tiho-Windows-x64.zip`
- `Tiho-Linux-x86_64.tar.gz`

Открой вкладку **Actions → Desktop Firefox ESR → последний успешный запуск → Artifacts**. Для Linux распакуй архив и запусти `./firefox`. Для Windows распакуй архив и запусти `firefox.exe`.

## Важно

Это первая настольная сборка, а не полное копирование Android-приложения. Пока нет мобильного «Банк»-режима, собственной оболочки вкладок, менеджера загрузок Тихо и встроенных локальных антифишинговых списков Android. Защита оплаты и доменные исключения RFP пока не переносятся. Настройки Firefox ESR и uBlock Origin применяются через штатные механизмы Mozilla.

Браузер поставляется без собственного установщика и без автоматического обновлятора Тихо. Обновления Firefox ESR приходят через новые сборки GitHub Actions; не отключай обновления безопасности ОС/браузера вручную.

## Проверка целостности

В каждом артефакте есть `SHA256SUMS.txt`. Сверяй хэш после скачивания, особенно если архив пришёл из неизвестного источника.
