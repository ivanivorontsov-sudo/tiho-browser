# Тихо для ПК

Настольная сборка Тихо для **Windows x64** и **Linux x86_64** на официальном Firefox ESR (движок Gecko). Android-приложение и его ключ подписи этим проектом не изменяются.

## Возможности

- Фирменная стартовая страница Тихо: поиск DuckDuckGo, Brave, Startpage, Яндекс и Google.
- Быстрые ссылки можно добавлять и удалять. Адреса проверяются, список сохраняется локально.
- Отдельный профиль Тихо, не смешанный с профилем другого установленного Firefox.
- «Тихо — Банк» запускает отдельный профиль с независимыми cookie, сессиями и хранилищем сайтов.
- «Тихо — Приватное окно» запускает штатный приватный режим Firefox.
- Вкладки, закладки, история, загрузки, поиск по странице и WebExtensions предоставляет Firefox ESR.
- uBlock Origin устанавливается из официального каталога Mozilla Add-ons.
- Политики приватности Firefox включают Enhanced Tracking Protection, HTTPS-Only, Global Privacy Control, защиту от фингерпринтинга и ограничение WebRTC.
- Для совместимости входа Google разрешены cookies только для `accounts.google.com` и `www.google.com`; там же действует точечное исключение из Resist Fingerprinting. Total Cookie Protection и остальные защиты сохраняются для всех остальных сайтов.

## Установка Linux

Для Debian 13, Ubuntu и совместимых систем x86_64:

```bash
sudo apt install ./Tiho-Linux-x86_64.deb
```

Запуск: `tiho`. Отдельный банковский профиль: `tiho-bank`. Приватное окно: `tiho-private`.

Основной профиль хранится в `$XDG_CONFIG_HOME/tiho/profile`, банковский — в `$XDG_CONFIG_HOME/tiho/bank-profile` (обычно под `~/.config/tiho/`). Удаление пакета не удаляет профили пользователя.

## Windows x64

Распакуйте `Tiho-Windows-x64.zip` в папку, доступную для записи:
- `Tiho.cmd` — обычный запуск;
- `Tiho-Bank.cmd` — отдельный банковский профиль;
- `Tiho-Private.cmd` — приватное окно.

Профили хранятся в `%APPDATA%\Tiho\profile` и `%APPDATA%\Tiho\bank-profile`.

## Проверки качества

CI проверяет JSON-политики, синтаксис JavaScript, unit-тесты быстрых ссылок, структуру DEB, desktop-файлы, shell launcher, установку/удаление пакета и запуск Firefox в headless-режиме с рендерингом локальной стартовой страницы. Эти проверки не заменяют ручное тестирование сайтов и графических драйверов на реальном устройстве.

## Ограничения и безопасность

Отдельный банковский профиль изолирует cookie и данные сайтов, но **не эквивалентен** мобильному экрану «Банк»: автоматическое распознавание платёжных доменов, блокировка снимков экрана и оверлеев, доверенные расширения и доменные исключения ещё не реализованы. Встроенный менеджер пользовательских скриптов и подписанные мобильные антифишинговые списки также не перенесены.

Не показываем фиктивный индикатор «защищено»: фактическая защита обеспечивается настройками Gecko и установленными расширениями. Firefox ESR поставляется с официальными бинарными файлами Mozilla. Проверка подписи расширений не отключается. Собственное расширение с привилегированным доступом к вкладкам, истории, загрузкам и банковским режимам должно быть подписано Mozilla перед включением в обычную сборку Firefox.

## Обновления и целостность

Обновления Firefox ESR для настольной сборки поставляются через GitHub Actions. Не отключайте обновления безопасности ОС. Пакет Linux и архив Windows сопровождаются SHA-256; сверяйте хэш после скачивания.
