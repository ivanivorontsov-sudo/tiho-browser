# Тихо для ПК

Настольная сборка Тихо для **Windows x64** и **Linux x86_64**.

## Что это

Настольная версия использует официальный Firefox ESR (движок Gecko), а не Chromium/Electron. Это сохраняет совместимость с Firefox WebExtensions и uBlock Origin. Поверх Firefox добавлены фирменная стартовая страница Тихо, быстрые ссылки с локальным сохранением, поисковая строка с выбором поисковика и оформление вкладок/панели в стиле мобильного приложения. Бинарники Mozilla не изменяются: интерфейсные файлы и политики устанавливаются отдельно.

## Защита по умолчанию

- uBlock Origin устанавливается принудительно из официального каталога Mozilla Add-ons.
- Enhanced Tracking Protection — Strict.
- HTTPS-Only включён.
- Global Privacy Control включён.
- Resist Fingerprinting включён (может ухудшать совместимость отдельных сайтов).
- WebRTC остаётся доступен, но ограничивается для снижения утечек IP.
- Убраны телеметрия Firefox, исследования, Normandy и спекулятивные сетевые запросы.
- Кросс-сайтовый Referer обрезается до origin.
- Cookies, история, кэш, активные сессии и данные форм очищаются при закрытии браузера; пароли и закладки не входят в этот список.

## Скачать Linux

Для Debian 13, Ubuntu и совместимых систем выпускается установочный пакет **`Tiho-Linux-x86_64.deb`** (архитектура amd64).

Установка:
```bash
sudo apt install ./Tiho-Linux-x86_64.deb
```

После установки браузер появится в меню приложений под названием **Тихо**. Запуск из терминала: `tiho`.

Пакет устанавливает Firefox ESR в `/opt/tiho/firefox`, стартовую страницу в `/opt/tiho/ui`, оформление `userChrome.css`, системный запускатель и политики приватности Тихо. Стартовая страница открывается при запуске браузера; быстрые ссылки сохраняются локально в профиле Firefox. Архив TAR.GZ больше не используется как основной способ установки Linux-версии.

Готовый DEB и файл SHA-256 публикуются в [GitHub Releases](https://github.com/ivanivorontsov-sudo/tiho-browser/releases/tag/desktop-v153.6.0).

## Важно

Это первый этап переноса дизайна, а не полное копирование Android-приложения. Вкладки, закладки, загрузки, историю, поиск по странице и расширения пока предоставляет сам Firefox ESR; фирменная оболочка вкладок и отдельный менеджер загрузок Тихо ещё не реализованы. Мобильный режим «Банк», локальные антифишинговые списки, доменные исключения RFP и мобильные пользовательские скрипты пока не перенесены. Не считай зелёный индикатор на стартовой странице самостоятельной проверкой безопасности: реальную защиту обеспечивают настройки Gecko и uBlock Origin.

Браузер поставляется без собственного установщика и без автоматического обновлятора Тихо. Обновления Firefox ESR приходят через новые сборки GitHub Actions; не отключай обновления безопасности ОС/браузера вручную.

## Проверка целостности

В каждом артефакте есть `SHA256SUMS.txt`. Сверяй хэш после скачивания, особенно если архив пришёл из неизвестного источника.
